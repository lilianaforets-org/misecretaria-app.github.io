Política de privacidad

Última actualización: 22 de noviembre de 2026

Mi Secretaria es una aplicación personal que se ejecuta en el ordenador de su única usuaria. Esta política explica qué datos usa y cómo los protege.

Datos de Google a los que accede

  • Google Calendar (permiso calendar.events): para mostrar sus próximas citas y, únicamente cuando ella lo confirma en la aplicación, crear citas nuevas.
  • Contactos de Google (permiso contacts.readonly, solo lectura): para encontrar el correo o teléfono de una persona cuando ella quiere escribirle.
  • Dirección de correo de la cuenta: para mostrar con qué cuenta está conectada.

Cómo se usan y se guardan

  • Los datos se procesan en su propio ordenador. No hay servidores de la aplicación ni base de datos en internet.
  • Los permisos de Google se guardan cifrados con el cifrado del sistema operativo y solo pueden leerse en ese ordenador.
  • Para resumir y organizar la información, la aplicación puede enviar textos al servicio de inteligencia artificial Gemini de Google, sujeto a las condiciones de Google.
  • No se venden, ceden ni comparten datos con terceros, ni se usan para publicidad.

Uso de datos de las API de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

Se puede desconectar Google en cualquier momento desde la propia aplicación (botón «Desconectar Google») o desde myaccount.google.com/permissions. Al hacerlo, se borran los permisos guardados en el ordenador.

Contacto

Para cualquier pregunta, se puede escribir al correo de asistencia que aparece en la pantalla de permisos de Google al conectar la aplicación.
